## Featured Projects

### [FinSentinel](https://github.com/kapurV06/FinSentinel)
Stock anomaly detection stacking Isolation Forest, an LSTM Autoencoder, and a DQN agent into one ensemble, wrapped in a Streamlit dashboard built to feel like a monitoring terminal rather than a demo. Tested across 15 tickers over 6 sectors with a chronological train/test split and event-anchored validation against known 2024 market events. Preprint live on SSRN, currently under journal review.

`Python` `PyTorch` `Streamlit` `Reinforcement Learning`

---

### [FULLHOUSE](https://github.com/kapurV06/fullhouse)
Rare disease diagnosis support pipeline — UMAP + HDBSCAN + XGBoost over HPO/Orphanet data, paired with an LLM layer running House MD-style differential reasoning. Faculty-rated 10/10.

`Python` `XGBoost` `UMAP/HDBSCAN` `Groq (Llama 3.3 70B)`

---

### [Meeting Intel](https://github.com/kapurV06/meeting-intel)
Local-first meeting intelligence tool. Transcribes a 30-minute meeting in ~90s via Groq Whisper Large V3, then pulls structured action items, decisions, and open questions in under 4s using Llama 3.3 70B. No cloud storage.

`FastAPI` `Groq Whisper` `Llama 3.3 70B`

---

### [OrbitDesk](https://github.com/kapurV06/orbitdesk-support-agent)
LangGraph-based customer support agent running entirely on local Hugging Face models — all-MiniLM-L6-v2 for embeddings, Qwen2.5-1.5B-Instruct for generation. No external API dependency.

`LangGraph` `HuggingFace` `Python`

---

### [FanLens](https://github.com/kapurV06/fanlens)
Reddit fan-theory aggregator with NLP topic clustering and AI-powered theory generation — scrapes discussion, clusters it with BERTopic, and generates new theories on top of the clusters. Built with Vue 3 and FastAPI.

`Vue 3` `FastAPI` `BERTopic` `NLP`

## How I Build

I'd rather ship something smaller that I can defend under questioning than something impressive-sounding I can't explain. Most of my projects reflect that — FinSentinel's numbers are backed by bootstrap confidence intervals and event-anchored validation, not just a headline metric. If a result looks too good, my first move is to go find out why, not to write it up.
